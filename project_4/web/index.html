Quality comparison

The quality of the two aren’t apparent in the chet baker one as it is composed mostly of large sized colors, but in the glicoman one we can see that the aliasing from the lights from the sign is stronger in Nearest Neighbours than Bilinear Interpolation. This is because NN takes the whole pixel value of one nearest pixel, which makes the contrast between pixels more apparent. This creates a jaggedness, which would strengthen the aliasing effect. On the other hand, Bilinear Interpolation smooths this effect by a weighted average of the surrounding pixels, which allows an illusion that the original level of aliasing was retained.

Speed vs. quality trade-offs

However, since NN just needs to assign the nearest neighbor, it is much faster compared to bilinear interpolation, which would need many more calculations per pixel.

A.4 Blend the Images into a Mosaic

Procedure

For all mosaics, I chose the middle image as the reference image and mosaiced images left and right to the reference image. Each pair (left & middle, middle & right) had their homography matrix computed.

Then, the size of the image plane that the pixels will be projected to is calculated using the min and max of the x and y from all projected corner pixels of the images. However, this could result in negative pixels, which is complemented by using a translation matrix warping later.

Once we found the size of the output plane, all images are projected onto the plane using inverse-warp with bilinear interpolation, which is then blended together.

To blend the images, I first applied a weighted average on the projected images. I did this by using the bwdist equivalent function in python scipy.ndimage.distance_transform_edt to smooth the alpha mask out by changing the values of each pixel to it’s distance to the nearest edge on the photo. This is applied to each photo’s alpha, then that new alpha mask is used as weight on how much it should be used in that output pixel. Then the average of the weighted pixels is used to determine the final output.

However, when I did this, I noticed that any misalignments that happened left a fade in the image, as averaging them makes details show up twice (in different locations).

Hence the second method, 2-level Laplacian was implemented. This splits each image into low frequencies and high frequencies, then blend the two bands differently. The alpha masks are each calculated the same as the weighted average, but we then determine another mask, that for each pixel, the index of the image whose edge is farthest from that pixel is assigned. For the low frequencies, a weighted average is applied similarly like before as lower frequencies cover color and brightness, which is smoothed out over averaging. But for the higher frequencies, we only take the pixel that is from the image that has the farthest edge for that pixel. This disallows the doubling effect of pixels from simple weighted averaging.

The final image is blended low band plus a selective high band. We can see that in doe, the people that were originally doubled has disappeared.

A.5 Bells & Whistles CS280A

Procedure

Since the straight edges of the images become curved on a cylinder, I sampled points along each edge and transformed with the homography matrix and then projected them onto a cylinder to determine the output plane size. Then I used inverse cylindrical mapping and the inverse homography to trace each output pixel back to its source image, where bilinear interpolation was used like before to calculate the value of the pixel. The resulting three cylindrical images were then blended with the same 2-level Laplacian method.

Choosing the focal length: Doe Library

I pick focal length of 4000 as the edges of the image are less round, which allows the ground to be less distorted.

Part B: Feature Matching for Autostitching

B.1 Harris Corner Detection

Corners and descriptors were computed on images downscaled to 0.25 for speed and so that the fixed 40x40 window covers a meaningful region as the 40x40 descriptor on the original image would be on too fine details.

For speed, ANMS was run on the 5000 strongest Harris corners instead of all corners, which is still far more than the resulting 500 corners it keeps.

Corners with and without ANMS: doe_2

When only checking the top 500 corners in strength, they tend to be dense in particular areas (on the buildings, which have more defined structures). However, after applying the ANMS method, we can see that the corners picked are evenly spread around the image, which are local maxima of that area.

B.5 Bells & Whistles: Multiscale Processing CS280A

Procedure

I implemented the multiscale processing option. For each image, I built a Gaussian pyramid (blur with sigma=1, then downsample by 2) with four levels at scales 0.5, 0.25, 0.125 and 0.0625. At every level I:

  • Detected Harris corners
  • Applied ANMS to the detected corners
  • Extracted feature descriptors
  • Mapped the corner coordinates back to the original image scale.

Features from all levels were matched together, and a single RANSAC estimated the homography used for the mosaic.

levels = 4 (scales 0.5, 0.25, 0.125, 0.0625) · 500 ANMS corners per level
